Can you trust the agent?

An inspectable lab for evaluating AI-assisted QA work. Explore what the agent did, what evidence it used, where it failed, and where a person stays in control.

Replay data: deterministic, illustrative portfolio scenarios, not a live benchmark or production client run. Cost and timing figures are estimates, not measured outcomes.
npm run agent:lab -- --scenario all
npm run agent:lab -- --scenario review --decision approve

Run from the repository root. Each command prints JSON from the checked-in replay corpus; review decisions stay local and never execute changes.
