Quick start · Node.js 20+

How to run this project

Clone the public repository, install the browser once, then run the tests or replay a demo. The AI agent replay works without an API key.

01

Get the code and install dependencies

git clone https://github.com/ibtsam2666/IbtsamAyyaz-Portfolio.git
cd IbtsamAyyaz-Portfolio
npm ci
npx playwright install chromium
02

Run the UI and API suites

npm run typecheck
npm test
npm run report

The suites exercise the public Sauce Demo and Restful Booker practice apps. The HTML report opens after the run.

03

Replay the AI test agent

npm run agent -- ai-test-agent/stories/cart-badge.md --replay

Uses a checked-in response to generate and run tests, then maps results to the story’s acceptance criteria. No model API key is needed.

04

Try mutation testing

npm run mutate -- ui-tests/tests/checkout.spec.ts
npm run mutate -- mutation-testing/examples/weak-assertions.spec.ts

The second example includes a surviving mutation to show how the report identifies an assertion to strengthen.

05

Try the MCP rerun demo

npx tsx mcp-rerun-server/smoke-client.ts

Starts the server over stdio and calls its demo tools. To run the live model-backed agent instead of replay mode, configure ANTHROPIC_API_KEY.

06

Explore and replay the AI agent lab

npm run agent:lab -- --scenario all
npm run agent:lab -- --scenario review --decision approve
npm run agent:lab -- --scenario triage

The browser lab and CLI cover evaluation, failure triage, a human review gate, tool traces, bounded recovery and cost/speed estimates. These deterministic fixtures need no API key, make no model call and never execute generated code. Figures are illustrative, not live benchmark results.
