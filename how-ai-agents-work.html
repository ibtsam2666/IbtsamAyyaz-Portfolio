Architecture and boundaries

How the QA agent demos work

This repository pairs a live, optional model-backed test-generation command with deterministic fixtures for repeatable portfolio demonstrations. The replay corpus is explicitly illustrative; it does not claim to be a measured client benchmark.

Story-to-test path

  1. Read a story and extract numbered acceptance criteria.
  2. Provide existing Playwright fixtures and page objects as project context.
  3. Ask the configured model for a test plan and criterion-tagged spec.
  4. Write the generated spec to the ignored local output directory.
  5. Run the focused Playwright spec and map results back to acceptance criteria.
  6. Save run metadata: model, elapsed time, token counts, results, and optional cost from operator-supplied rates.

The live command needs an Anthropic API key. The recorded response replay needs no key and makes no model call.

Evaluation and evidence

The lab scores a fixed five-story fixture using the same criteria-coverage and valid-passing rubric for a simple baseline, the agent replay, and a human reference. Story-level evidence calls out failed checks, weak assertions, surviving mutations, and unmapped criteria. The fixture is useful for reviewing the reporting logic, not for claiming model quality in general.

Failure classification uses visible deterministic rules over HTTP status, browser health, reproducibility, retries, fixture validity, and value mismatch. It is a rules-based comparison, not a model diagnosis.

Human control

The review demo records a reviewer label, decision, rationale, and timestamp to local browser storage. Approval is a display state only. It never runs a test, writes a patch, opens a pull request, or publishes anything.

The recovery scenario advances through a fixed locator-drift example. It limits attempts, keeps the assertion intact, and ends with a review request. It is not an autonomous code repair integration.

Run it

npm run agent -- ai-test-agent/stories/cart-badge.md --replay
npm run agent:lab -- --scenario all
npm run agent:lab -- --scenario all --format html --out agent-lab-report.html

For an optional live run, see the setup notes in the agent lab. Token costs are estimated only when you supply rates; usage and runtime are read from the live provider response and local test run.
