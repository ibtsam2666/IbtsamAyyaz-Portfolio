Public project · AI-assisted test generation

From a cart story to tested behavior

A reproducible example of an AI test agent using existing fixtures and page objects, mapping generated tests back to acceptance criteria, and reporting coverage.

PlaywrightTypeScriptSauce DemoRecorded replay

1. The problem

The story asks for a cart badge that stays in sync as a shopper adds or removes products. Five acceptance criteria cover increment, decrement, empty state, cart-page consistency, and persistence after reload.

  1. Adding a product increases the badge by one.
  2. Removing a product decreases the badge by one.
  3. An empty cart has no badge.
  4. The badge matches the cart contents.
  5. The count survives a page reload.
Read the full story →

2. Ground generation in the repo

The agent reads the story plus the existing shop fixture and page objects. Its prompt requires use of the signed-in fixture, existing methods and criterion-numbered test titles. This avoids raw login setup and keeps generated tests in the framework's style.

Inspect the agent →

3. Generate five tests

Replay mode uses a checked-in model response. The generated spec covers each criterion with a concrete count or empty-state assertion.

test('[AC1] adding a product increases the badge by one', ...)
test('[AC2] removing a product decreases the badge by one', ...)
// AC3, AC4 and AC5 are also mapped to tests.
Read the generated spec →

4. Run and map the results

5 of 5 acceptance criteria covered · 5 tests passed in the recorded run

The agent parses the JSON test report, associates each test title with its criterion number, and lists criteria with no passing test as gaps. The checked-in replay output makes this flow reviewable without an API key.

AC1 ✓ covered  Adding a product increases the badge by one.
AC2 ✓ covered  Removing a product decreases the badge by one.
AC3 ✓ covered  When the cart is empty, no badge is shown.
AC4 ✓ covered  The badge count matches the cart contents.
AC5 ✓ covered  The count is kept after reload.

Every acceptance criterion has a passing test.

5. Reproduce it

npm ci
npx playwright install chromium
npm run agent -- ai-test-agent/stories/cart-badge.md --replay
